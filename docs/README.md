# Documentation

## Intervals.icu OpenAPI Reference

`openapi-spec.json` is a bundled upstream Intervals.icu OpenAPI reference
snapshot. It is included so contributors can inspect Intervals.icu request and
response shapes while working on the read-only MCP and CLI surfaces.

The file is not generated by this project and does not define this server's
public behavior. It includes Intervals.icu write and delete endpoints because
the upstream API includes them.

This repository's MCP tools and CLI commands are intentionally read-only. The
supported Intervals.icu calls are implemented in
`internal/adapters/intervalsicu`, which uses authenticated `GET` requests for
the current feature set. Any future write support should be treated as an
explicit product and security change, with matching docs, tests, and review.
